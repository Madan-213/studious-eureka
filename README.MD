# SkillMatch AI - Jobs Board Application

An AI-powered Job Board built with Next.js, TypeScript, and Tailwind CSS for the GlobalCo Software Engineer Assessment.

## 🚀 Key Features
- *Job Directory:* Browse open developer positions.
- *AI Job Summarizer:* Instant high-level summaries of candidate requirements using AI.
- *Automated CI/CD:* Continuous Integration & Deployment pipeline using GitHub Actions and Vercel.

## 🛠️ Tech Stack
- Next.js / React
- TypeScript
- Tailwind CSS
- GitHub Actions & Vercel
